## 📋 Modules

### 👨‍🎓 Student Management
- Student Registration & Profiles
- Sibling Management & Discounts
- Bulk Import (CSV)
- Student Promotion with Fee Carry-forward
- Early Departure Tracking

### 💰 Fee Management
- Monthly/Annual/Admission Fee
- Fee Challan & Slips (PDF)
- Fee Collection (Full/Partial/Advance)
- Fine, Discount, Refund
- Fee Defaulters Report
- Daily Cash Report & Student Ledger
- Receipt & Voucher Generation

### 📚 Academics
- Classes, Sections, Subjects
- Lesson Planner (Weekly + Daily)
- Homework Tracker
- Syllabus Management (1st/2nd/Final Term)
- Timetable

### 📝 Examinations
- Monthly Test, Mid-Term, Final Term
- Subject-wise Marks (Written/Oral/Practical)
- Result Card & Progress Report
- Top Position Holders

### 📊 Attendance
- Daily Attendance Marking
- Late Comers Tracking
- Monthly Attendance Report
- Parent WhatsApp Notifications

### 👩‍🏫 Staff Management
- Teacher & Staff Profiles
- Attendance & Payroll
- Teacher App

### 🖨️ Print Formats (15+)
- Admission Form, Fee Challan, Attendance Sheet
- Report Card, ID Card, Staff Register
- Monthly Slips, Performance Appraisal & more

### 📱 Communication
- WhatsApp Fee Reminders & Attendance Alerts
- SMS Integration & Notice Board
- Parent App

### 🔐 Administration
- Role-Based Access Control (Admin/Teacher/Staff)
- Academic Sessions & Terms
- Data Backup to GitHub
- Admin Dashboard

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React + TypeScript + Vite |
| Backend | Convex (Real-time DB + Functions) |
| Styling | Tailwind CSS + shadcn/ui |
| Auth | Convex Auth (Email OTP) |
| Storage | Supabase Storage |
| PWA | Service Worker + Web Manifest |
